* Social Network Analysis in Python3
** Introduction
This tutorial will guide you through performing social network analysis using Python3, focusing on the relationships between committers and authors from a CSV file.

** The Dataset

 We're using the dataset from zenodo here:

 Dhaouadi, M., Oakes, B., & Famelis, M. (2023, November 1). Rationale
 Dataset and Analysis for the Commit Messages of the Linux Kernel
 Out-of-Memory Killer. https://doi.org/10.5281/zenodo.10063089

 https://zenodo.org/records/10063089/files/dataset_3_labels_merged.csv?download=1

** Load the CSV File
We will load `dataset_3_labels_merged.csv`, which uses semi-colons as delimiters.

#+BEGIN_SRC python
import csv
from collections import defaultdict

# Load the CSV file
graph_data = defaultdict(list)
with open('dataset_3_labels_merged.csv', mode='r', newline='', encoding='utf-8') as file:
    reader = csv.DictReader(file, delimiter=';')
    for row in reader:
        committer = row["committer name"]
        author = row["author name"]
        graph_data[committer].append(author)

print("Data loaded successfully.")
#+END_SRC

#+RESULTS:
: Data loaded successfully.

** Create the Graph
We'll create a directed graph from the relationships between committers and authors.

#+BEGIN_SRC python
import networkx as nx

# Create graph
G = nx.DiGraph()
for committer, authors in graph_data.items():
    for author in authors:
        G.add_edge(committer, author)

print("Graph created with nodes and edges.")
print(G)
#+END_SRC

#+RESULTS:
: Graph created with nodes and edges.
: DiGraph with 98 nodes and 100 edges

** Plot the Graph
We'll use Matplotlib to visualize the graph.

#+BEGIN_SRC python
import matplotlib.pyplot as plt

# Drawing the graph
plt.figure(figsize=(12, 8))
pos = nx.spring_layout(G)
nx.draw(G, pos, with_labels=True, node_size=2000, node_color="skyblue", font_size=10, font_color="black")
plt.title("Committer-Author Relationship Graph")
plt.show()
#+END_SRC
