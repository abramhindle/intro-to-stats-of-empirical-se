* Granger Causality in R
** What is Granger Causality?

Granger causality is a statistical concept used to determine whether
one time series can predict another. It's particularly useful in
econometrics and time series analysis to understand potential causal
relationships between variables.

You'll typically use one of these packages:
- lmtest package: Most common for basic Granger causality tests
- vars package: More comprehensive for vector autoregression models

** Cook's Distance: Identifying Influential Observations

Cook's distance helps identify influential data points that
disproportionately affect regression models.

Why remove high leverage points?
- Reduces model bias
- Prevents outliers from skewing statistical relationships
- Improves model reliability and interpretability

#+BEGIN_SRC R
# Function to remove high leverage points
remove_high_leverage_points <- function(x, y) {
  model <- lm(y ~ x)
  cooksd <- cooks.distance(model)
  
  # Threshold: 4/n (n is number of observations)
  threshold <- 4 / length(x)
  
  # Remove points exceeding threshold
  indices <- which(cooksd < threshold)
  
  return(list(
    x = x[indices],
    y = y[indices]
  ))
}

# Apply to each dataset
clean_data1 <- remove_high_leverage_points(x1, y1)
clean_data2 <- remove_high_leverage_points(x2, y2)
clean_data3 <- remove_high_leverage_points(x3, y3)

** Augmented Dickey-Fuller (ADF) Test: Checking Stationarity

Stationarity is crucial in time series analysis. The ADF test checks
if a time series is stationary.

Why is stationarity important?
- Ensures consistent statistical properties
- Prevents spurious regression results
- Validates time series modeling assumptions

Stationarity in a timeseries:

- Constant Mean: The average value of the series remains constant over time.
- Constant Variance: The variability or spread of the series does not change with time.
- Constant Autocovariance: The correlation between values at different times depends only on the lag between them, not on actual time.


#+BEGIN_SRC R
# ADF Test for Stationarity
adf_test <- function(data) {
  adf_result <- adf.test(data)
  print(adf_result)
  
  # Interpret results
  if (adf_result$p.value <= 0.05) {
    cat("Series is stationary (reject null hypothesis)\n")
  } else {
    cat("Series is non-stationary (fail to reject null hypothesis)\n")
  }
}

** Interpreting ADF Results

*** Interpretation Guidelines:

The null hypothesis of the Dickey-Fuller test is that a time series
has a unit root, meaning it is non-stationary and exhibits a random
walk behavior. In contrast, the alternative hypothesis is that the
time series is stationary.

A unit root means that a time series is non-stationary and has a
characteristic where shocks to the series have permanent effects.
Specifically, a time series with a unit root follows a random walk,
which implies that its mean and variance are not constant over time,
making it unpredictable and dependent on its past values.

An example of a time series without a unit root is a stationary time
series, such as white noise. For instance, consider a series of random
values generated from a normal distribution with mean zero and
constant variance.

1. p-value < 0.05: Non-stationary
2. p-value ≥ 0.05: Stationary


** Granger Causality: Understanding Temporal Relationships

*** Why Granger Causality?
Granger causality tests whether one time series is useful in forecasting another:
- Examines predictive causality
- Determines if past values help predict future values
- Goes beyond simple correlation

If lagged timeseries correlate therefore maybe the lagged timeseries causes the response.


#+BEGIN_SRC R
# Granger Causality Test Function
perform_granger_causality <- function(x, y) {
  # Ensure data is in time series format
  x_ts <- ts(x)
  y_ts <- ts(y)
  
  # Perform Granger causality test
  # Different lag specifications
  lags <- c(1, 3, 5)
  
  for (lag in lags) {
    # Test X causes Y
    x_to_y <- grangertest(y_ts ~ x_ts, order = lag)
    
    # Test Y causes X
    y_to_x <- grangertest(x_ts ~ y_ts, order = lag)
    
    cat("\nGranger Causality Test (Lag =", lag, ")\n")
    
    # Interpret X to Y causality
    if (x_to_y$`Pr(>F)`[2] < 0.05) {
      cat("X significantly Granger-causes Y (p <", 
          x_to_y$`Pr(>F)`[2], ")\n")
    } else {
      cat("X does not Granger-cause Y\n")
    }
    
    # Interpret Y to X causality
    if (y_to_x$`Pr(>F)`[2] < 0.05) {
      cat("Y significantly Granger-causes X (p <", 
          y_to_x$`Pr(>F)`[2], ")\n")
    } else {
      cat("Y does not Granger-cause X\n")
    }
  }
}

# Apply Granger causality to datasets

cat("\nDataset 2 (Lagged Correlated):\n")
perform_granger_causality(clean_data2$x, clean_data2$y)

cat("\nDataset 3 (Uncorrelated):\n")
perform_granger_causality(clean_data3$x, clean_data3$y)

** Interpreting Granger Causality Results

*** Interpretation Guidelines:
1. p-value < 0.05: Significant Granger causality
2. p-value ≥ 0.05: No significant Granger causality
3. Asymmetric results possible (X causes Y, but not vice versa)

** Dangers

- *Spurious Relationships*: Correlation does not imply causation. Variables may appear related due to confounding factors or common causes.
- *Lag Specification*: Choosing incorrect lags can lead to misleading results. The choice of lag length can affect interpretations significantly.
- *Model Misspecification*: The underlying model may not capture all relevant dynamics, leading to incorrect conclusions.
- *Stationarity Assumption*: Granger causality tests require stationary time series. Non-stationary data can produce unreliable results.
- *Overfitting*: Including too many lags may lead to overfitting, where the model fits noise rather than the true underlying relationship.
- *Asymmetry Risks*: It can suggest asymmetrical relationships, where one variable is said to cause another without confirming the reverse.
- *Interpretation Risks*: Misinterpretation

** Granger is multidimensional 

To illustrate here's a multivariate Granger causality test, where three time series (X1, X2, X3) cause Y in the first example and do not cause Y in the second example.

*** Example 1: X1, X2, and X3 cause Y


#+begin_src R
# Create time series data
n <- 100
Y <- ts(rnorm(n))
X1 <- ts(runif(n))
X2 <- ts(rnorm(n))
X3 <- ts(rnorm(n))

# Simulate Y as a function of past values of X1, X2, and X3
for (t in 4:n) {
  Y[t] <- 0.5 * Y[t - 1] + 0.9 * X1[t - 2] + 0.5 * X2[t - 3] + 0.3 * X3[t - 1] + rnorm(1)
}

# Combine into a data frame
data <- data.frame(Y, X1, X2, X3)

# Fit a VAR model
var_model <- VAR(data, p = 3)

# Perform Granger causality test
causality_results <- causality(var_model, cause = c("X1", "X2", "X3"))

# Print results
print(causality_results)
